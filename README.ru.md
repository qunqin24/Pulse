- **Семьдесят семь сервисов на одной ленте** — Claude Code, Codex, Cursor, GitHub Copilot, Antigravity, Kiro, Grok, DeepSeek, Kimi Code и многие другие, у каждого своё кольцо.
- **Без аккаунта и сервера Pulse** — используются входы, которые у вас уже есть, и ничего никуда не отправляется.
- **Только настоящие цифры** — каждый процент расхода взят из того, что сообщил сам сервис. Немногие оценки так и помечены, а если сервис ничего не сообщает, Pulse говорит об этом, а не угадывает.
- **Родное и ненавязчивое приложение** — Swift и SwiftUI, Liquid Glass в macOS 26. Прикрепите ленту слева, справа, сверху или снизу рядом с Dock, дайте ей сворачиваться в узкую полоску без дела или держите её в строке меню.

## Установка

1. Скачайте последний **`Pulse-x.y.z.dmg`** со страницы [Releases](https://github.com/qunqin24/Pulse/releases/latest).
2. Откройте образ диска и перетащите **Pulse** в папку `Программы`.
3. При первом запуске выберите сервисы, которые нужно отслеживать. Сначала ни один не отмечен; Pulse читает их учётные данные и проверяет расход только после того, как вы нажмёте **Готово**. Если закрыть окно выбора, отслеживание останется выключенным; включить сервис можно и в настройках. При обновлении ваш выбор сохраняется, а о новых сервисах, найденных на вашем Mac, Pulse спросит один раз.
4. Pulse живёт в строке меню. Если в ней тесно, щёлкните правой кнопкой по плавающей ленте — или по свёрнутой полоске — и выберите **Настройки…**; можно также назначить глобальное сочетание клавиш в **Настройки › Основные › Сочетания клавиш**.

> [!NOTE]
> **Первый запуск и Gatekeeper**:<br>
> Pulse — проект с открытым исходным кодом без сертификата разработчика Apple. При первом запуске macOS может заблокировать приложение:
> - **Способ 1 (интерфейс)**: запустите Pulse, закройте предупреждение, откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.
> - **Способ 2 (Терминал)**:
>   ```bash
>   xattr -cr /Applications/Pulse.app
>   ```
>   *Обновления приходят внутри приложения через Sparkle. После обновления macOS может снова запросить доступ к связке ключей браузера.*

## Основные возможности

### Кольца с первого взгляда
- **Цвет следует за расходом** — от зелёного через жёлтый к красному или свой цвет для каждого аккаунта.
- **Использовано или осталось** — `использовано 75%` или `осталось 25%`, с дополнительной дугой времени: какая часть окна уже прошла.
- **Активность в реальном времени** — вращающаяся точка, пока агент работает, и по желанию анимированные роботы, которые реагируют на каждый аккаунт.

### Подробности при наведении на кольцо
- **Все лимиты и время их сброса** на одной карточке, сплошными или сегментированными полосами.
- **Подробная карточка** — тариф, время чтения, оценочная стоимость каждого лимита и недавний расход по записям этого Mac.
- **Прогноз расхода** — предупреждает, если при текущем темпе лимит закончится раньше окна.
- **В строке меню** — самое заполненное кольцо в виде числа, маленького кольца или раздельных лимитов, с дополнительной панелью.

### Не мешает работать
- **Любой край** — слева, справа, сверху, рядом с Dock или в любом месте; без дела лента сворачивается в узкую полоску.
- **Уведомления, которые вы выбираете** — лимит пересёк порог, израсходован, сброшен, проверки не проходят, баланс заканчивается, у сервиса сбой.
- **Шесть языков** — английский, упрощённый и традиционный китайский, японский, корейский и русский.
- **Дополнительно** — глобальные сочетания клавиш, переход на активный дисплей, скрытие на снимках экрана.

### Расход, статус и остальное
- **Расход токенов** — сколько израсходовали 54 локальных клиента, по ценам публичных API, по дням, моделям и агентам, за любой выбранный период.
- **Оценки в вашей валюте** — доллары, юани, гонконгские или новые тайваньские доллары, иены, воны или рубли.
- **Итоги использования** — карточки за день, неделю, месяц или год, которыми можно поделиться; они строятся по тем же записям.
- **Статус сервисов** — собственные страницы статуса 44 сервисов и уведомление, когда одна из них сообщает о сбое.
- **Диагностика подключения** — откуда взялась каждая цифра и что ответили серверы.
- **Для опытных пользователей** — несколько аккаунтов у одного сервиса, расширения для собственных источников, `Pulse --json` для скриптов.

## Поддерживаемые сервисы и способы чтения

77 сервисов, и каждый читается так, как работает сам продукт: через его собственный адрес расхода, вход редактора, локальный языковой сервер или вставленный вами ключ, — а каждый процент взят из того, что сообщил сервис. ## Конфиденциальность и безопасность

- **Без аккаунта и сервера Pulse** — ваш Mac обращается к сервисам, которыми вы пользуетесь, под вашими собственными входами.
- **Пять видов подключений, все перечислены** — сами сервисы, их публичные страницы статуса, [models.dev](https://models.dev) для цен моделей, [ExchangeRate-API](https://www.exchangerate-api.com) только если вы выбрали валюту, отличную от доллара, и GitHub/Sparkle для обновлений.
- **Ваши ключи остаются на вашем Mac** в зашифрованном виде, а записи о расходе, которые читает Pulse, никогда его не покидают.

[Подробнее](Docs/features.md#privacy-and-security) (на английском).

## Сборка из исходного кода

Pulse написан на Swift и SwiftUI. Для сборки текущих исходников нужен полный **Xcode** (не Command Line Tools) с **macOS 26 SDK**; приложение работает на **macOS 14+**.

```bash
# Клонировать репозиторий
git clone https://github.com/qunqin24/Pulse.git
cd Pulse

# Собрать пакет приложения
./Scripts/bundle.sh

# Запустить
open build.noindex/Pulse.app
```

`swift run Pulse` позволяет быстро собрать и запустить приложение без пакета, но уведомления и обновления внутри приложения работают только в собранном пакете. Настройка инструментов — в [Docs/build-from-source.md](Docs/build-from-source.md); выпуск новой версии — в [Docs/releasing.md](Docs/releasing.md) (на английском).
